const int LED_PIN = 2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  for (int duty = 0; duty <= 255; duty += 5) {
    analogWrite(LED_PIN, duty);
    delay(20);
  }
}
from machine import Pin, PWM
import time

pwm = PWM(Pin(2), freq=1000)

while True:
    for duty in range(0, 1024, 20):
        pwm.duty(duty)
        time.sleep_ms(20)
03

Perceptrones y Regresión Lineal

Introducción a modelos supervisados básicos: el perceptrón como unidad neuronal de suma ponderada con función de activación, y la regresión lineal para ajustar una función continua minimizando el error cuadrático medio (MSE).

Formulación Matemática

Cada entrada se multiplica por un peso sináptico y se suma un sesgo para generar la salida del modelo:

Perceptrón: y = f(∑ wᵢ·xᵢ + b)
Regresión:  ŷ = w·x + b
Costo MSE:  (1/n) · ∑(yᵢ - ŷᵢ)²
Ajuste Lineal MSE: 0.0
